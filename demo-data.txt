# [post]      文章标题 | 分类 | 内容 [| 关联产品品类]

# [product]   字段顺序如下，8 号之后的选填字段可以整体省略（不用补空 ||）：
#   0  标题
#   1  品类
#   2  品牌
#   3  现价
#   4  原价
#   5  购买链接
#   6  推荐指数（1-5）
#   7  商品详情
#   ---- 以下选填 ----
#   8  规格
#   9  适合人群
#   10 成分
#   11 优惠信息      ← 已废弃：这一列会被忽略
#   12 推荐理由
#   13 优点          ← 多个条目用分号 ; 分隔，导入后自动变成"一行一个"
#   14 缺点          ← 同上
#   15 用户评论      ← 同上，前台做成滑动轮播
#   16 自定义属性    ← 同上，数量不限；填「名称：值」会渲染成规格表的键值行
#   17 服务说明      ← 填「是」会自动转成服务说明标签；也可以直接写一串，用空格分隔
#   18 关联文章分类  ← 填文章分类名称，多个用分号 ; 分隔
#   19 首页热门（是 / 否）
#
# 多段正文写法：
#   商品「商品详情」里可以用 \n 表示换行，写成多段。
#
# 注意：
#   13-16、18 号字段用分号分隔多个值，所以这些字段的内容里不要再出现分号。
