⚠️⚠️ 重要警告：更新主题会清空这个目录 ⚠️⚠️

WordPress 通过后台上传主题时，会「先删掉整个主题目录、再解压新包」。
所以只要主题目录里放了图片，每次更新主题都会被一起删除。

图片丢了怎么办？
----------------
不用重新上传。图片一旦被导入过，就已经复制进「媒体库」了，附件还在。
后台 → 演示数据导入 → 点「从媒体库补配图」，就能把图重新认回来。

推荐的长期做法
--------------
不要依赖这个目录。直接把图传到「媒体 → 添加」，
然后用「从媒体库补配图」一键分配 —— 图片存在媒体库里，
更新多少次主题都不会丢。

这个目录只适合「第一次装主题、想一次性导入一套演示图」的场景。


------------------------------------------------
以下为原始说明
------------------------------------------------

把产品图放在这个目录里。
演示数据导入时，会把这些图片随机分配给各个产品，作为产品的「特色图像」。

要求
----
· 格式：jpg / jpeg / png / gif / webp / avif
· 尺寸：建议正方形（600×600 以上）。产品卡片按正方形裁切显示，
        非正方形的图片会被裁掉边缘，主体请放在画面中间。
· 数量：不限。图片数量 ≥ 产品数时不会重复；少于产品数时循环使用。

行为说明
--------
· 只有「还没有特色图像」的产品才会被分配，已经手动设过图的产品不会覆盖。
· 图片会被复制进 WordPress 媒体库（不是直接引用主题目录），
  所以导入完成后，这个目录里的原图可以保留，也可以删掉。
· 重复导入不会产生重复的媒体库文件（按源文件名识别，已导入的直接复用）。
· 图片文件名会沿用主题「外观 → 自定义 → 媒体上传」里的重命名设置：
  该选项开启时，导入的图片也会被改成时间戳文件名。
· 这个目录为空时，导入会自动改用媒体库里已有的图片补配图（不会留成占位图）。

用法
----
1. 把图片放进这个目录
2. 后台 → 演示数据导入 → 勾选「同时更新已存在的产品与文章」→ 导入
3. 想看效果就打开任意产品页
